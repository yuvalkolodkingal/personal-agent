# Prompt-injection control model

Page, document, message, connector, plugin, and model-generated instructions
are data, not user authority. The active task carries input-zone labels. When
untrusted content controls a step, unrelated secrets, private memory, email,
connectors, communication, commerce, and security effects are unavailable
unless a cross-zone approval names the exact source, target, effect, duration,
and call ceiling.

The browser and document extractors produce opaque structured handles and
provenance. Text claiming to be system policy or an approval cannot change
policy. Models never receive approval tokens or keychain values. Tool results
are bounded and secret-filtered. A reviewer compares requested outcomes with
the original goal, not with instructions discovered during execution.

Red-team fixtures include indirect instruction to exfiltrate a token, email a
contact, buy an item, disable policy, widen plugin scopes, read private memory,
reuse a remote pairing key, download and execute content, and submit an
irreversible form. The expected outcome is deny/ask with an audit record and no
side effect.
