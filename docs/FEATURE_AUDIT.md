# Personal Agent implementation audit

This file records what the desktop app actually supports as of 2026-08-29. “Partial” means useful production code or a working bounded workflow exists, but the complete cross-platform user workflow is not connected end to end. A helper executable being installed is not treated as proof that an operating-system permission was granted.

| Area                       | Status      | Current implementation                                                                                                                                          | Remaining work                                                                       |
| -------------------------- | ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| Chat, providers and models | Implemented | Authenticated pinned OpenCode sidecar, OAuth/API-key connections, model discovery, one global model picker, streamed turns, stop and timeout recovery           | Continue compatibility testing as OpenCode APIs evolve                               |
| English wake/STT/TTS       | Implemented | Continuous local phrase wake recognition, Moonshine Medium Streaming, Smart Turn v3.2 and Qwen3-TTS 0.6B; Whisper and Piper fallbacks; Voice Lab controls       | Hardware-specific performance tuning and broader packaging tests                     |
| Screen context             | Partial     | Browser workspace screen panel, active-window metadata, generation-bound semantic graph, secure-surface/exclusion policy, ephemeral validated frames and native status/permission display; bounded real Linux AT-SPI tree; ephemeral user-consented XDG ScreenCast negotiation with cancellation, cleanup and selected-stream metadata | Connect the portal PipeWire file descriptor to a bounded frame consumer; add UIA and AXUIElement trees; replace remaining command capture with WGC/ScreenCaptureKit; add per-app exclusion editor |
| Desktop visual control     | Partial     | Typed focus/click/type/scroll/launch/drag contracts, call-scoped approval, stale-handle rejection and fresh-snapshot postcondition verification; real Linux AT-SPI actions; XDG RemoteDesktop consent/session adapter and pointer-axis routing when the host portal exposes it | Current Hyprland portal does not expose RemoteDesktop; add portal absolute pointer/button handling, signed Windows UIA/SendInput and macOS AX/CGEvent helpers, coordinate/vision fallback and broader real-app verification |
| Dictation/live correction  | Partial     | Agent/Dictation modes, streaming partials, review-before-send, UTF-16-safe in-app edits, correction/formatting/undo commands, barge-in and duplicate-send protection | Apply edits to focused native text controls; app-specific rich-text/IDE adapters; end-to-end latency and accuracy benchmarks |
| Persistent memory          | Implemented | Encrypted facts plus reviewed writing style, namespaced project graph and conflict links; explicit saves, hybrid recall, model-context injection, provenance and complete review UI | Replace the deterministic local feature-hash embedder with a pinned neural embedder after distribution-size evaluation |
| Sessions/history           | Implemented | Create/resume/rename/delete, bulk selection, bounded recent list, search/filter and recovery from stale sessions                                                | Optional archive/export workflows                                                    |
| Goals/tasks                | Partial     | Durable task-graph supervisors, encrypted restart snapshots, resident OpenCode execution, checkpoint/session binding, native approval suspension/resume, pause/resume/cancel/retry controls, live results and creation UI | Add multi-node dependency editing, per-delegate worktree/profile isolation in the desktop executor, and longer cross-platform recovery soaks |
| Browser                    | Partial     | Isolated W3C WebDriver lifecycle, cross-platform Firefox/Chromium/Edge/Safari driver selection, allow/deny policy, DOM snapshots, generation-bound click/type and visible takeover controls | Package or guide browser drivers, add BiDi event support and downloads, verify personal-profile opt-in, and optionally embed a visible browser surface |

| Artifacts                  | Implemented | Encrypted content-addressed text and binary artifacts, immutable source-linked versions, integrity-checked previews, restore-as-new-version, no-overwrite export and responsive whiteboard pin/focus/copy/reorder controls | Provider-specific document/media generation remains supplied by configured skills and packs |
| Automations                | Implemented | Responsive desktop manager backed by encrypted scheduler snapshots, restart-safe missed-run recovery, enable/disable/delete/run-now controls, a resident isolated-session executor, bounded concurrency/failure pauses, live results and native approval suspension | Add resident adapters for file, connector, webhook, network/device and semantic event triggers; resumable background clarification remains explicit unsupported state |
| App integrations           | Partial     | GUI templates plus native PKCE/state/loopback OAuth for GitHub, Gmail and Google Calendar; access/refresh tokens live only in the OS keychain, scopes are reviewed read-only subsets, cancellation/retry is single-flight, Google refresh/revoke and automatic expiry refresh are wired, and all connectors retain separate grants and bounded REST requests | Slack/Microsoft OAuth, connector-specific pagination/events/actions, egress/rate-limit handling, and GitHub remote revocation (requires a confidential app secret, so the app performs an explicit local revoke with guidance) |
| Skills/MCP                 | Implemented | Full GUI lifecycle for stdio/HTTP/SSE definitions, import/export, permissions, health/logs, test-tool confirmation, update/rollback/uninstall, persistent OpenCode synchronization and one-click remote OAuth through the native policy gateway | API-key keychain setup wizard, signed remote catalog, and direct legacy-SSE test sessions remain optional compatibility enhancements |
| Usage/egress               | Partial     | Encrypted provider-neutral token and provider-reported cost accounting by turn/session/day/scope, budget evaluation, content-free web/MCP/connector egress receipts, filters, dashboard and private no-overwrite JSON export | Add provider request-byte accounting, PTY/process network receipts, broader connector coverage and live provider cost-shape compatibility evidence |
| Notifications              | Partial     | Cross-platform Tauri native delivery for automation completion, approval and failure routes; UTC quiet-hours suppression, privacy-bounded toast text, delivery diagnostics and in-app allow-once/reject handling | Desktop toast action buttons are unsupported by Tauri and stay in-app; add notification-center history and OS permission onboarding telemetry |
| Updates                    | Not wired   | Release verification/config primitives                                                                                                                          | Signed update feed, download UI and atomic installer                                 |

The app deliberately does not grant unrestricted filesystem, shell, browser or connector access directly from model text. Those effects must pass through authenticated OpenCode capabilities and the native policy boundary.
