# Contributing

Contributions are welcome under Apache-2.0. Start with a capability ID and
acceptance test. Security-sensitive changes include a threat-model update.
Platform adapters return explicit support state. New dependencies are exact,
licensed for distribution, and added through a tested pull request.

Never commit credentials, signing material, transcripts, memory, browser
profiles, or fixtures derived from real personal data. Do not modify the
legacy Jarvis repository from Personal Agent tooling.

Before submitting, run the commands in
`docs/operations/development.md`. A feature is not complete when tests are
skipped, output is a placeholder, or an unsupported path silently no-ops.
